**Конкретный бизнес-процесс:** анализ истории владения автомобилями клиентами системы PitGo.

В рамках процесса фиксируется начало владения автомобилем, завершение владения, клиент-владелец, автомобиль, тип владения и статус владения

**Уровень детализации (grain):** одна запись в таблице фактов представляет один период владения конкретным автомобилем конкретным клиентом.

Период владения определяется датой начала (`started_at`) и, если владение завершено, датой окончания (`ended_at`). Один клиент может иметь несколько периодов владения различными автомобилями, а один автомобиль может иметь несколько периодов владения разными клиентами в разные моменты времени.

**Таблицы измерений (dimension tables).**

### 1. `dim_customer` — измерение клиента

Описывает **кто владеет автомобилем**. Содержит характеристики клиента, являющегося владельцем автомобиля

| Атрибут          | Описание               |
| ---------------- | ---------------------- |
| `customer_key`   | Surrogate key в DWH    |
| `customer_id`    | ID клиента из PitGo    |
| `status`         | Статус клиента         |
| `phone_verified` | Подтверждён ли телефон |

---

### 2. `dim_vehicle` — измерение автомобиля

Отвечает на вопрос **каким автомобилем владеет клиент**. Содержит характеристики автомобиля, участвующего в процессе владения.

| Атрибут       | Описание               |
| ------------- | ---------------------- |
| `vehicle_key` | Surrogate key          |
| `vehicle_id`  | ID автомобиля из PitGo |
| `status`      | Статус автомобиля      |
| `brand`       | Марка                  |
| `model`       | Модель                 |
| `year`        | Год выпуска            |

Я добавил `brand`, `model` и `year` в прошлом дз их небыло

---

### 3. `dim_date` — измерение даты

Отвечает на вопрос **когда происходило владение**. Календарное измерение, используемое для анализа начала и окончания периодов владения во времени.

| Атрибут       | Описание    |
| ------------- | ----------- |
| `date_key`    | Ключ даты   |
| `full_date`   | Полная дата |
| `day`         | День        |
| `month`       | Месяц       |
| `quarter`     | Квартал     |
| `year`        | Год         |
| `day_of_week` | День недели |

**Star Schema**:

```
             dim_customer
                  |
                  |
	dim_vehicle — FACT — dim_date
```

**Таблица фактов `fact_vehicle_ownership`** хранит информацию о периодах владения автомобилями клиентами. Каждая запись соответствует одному периоду владения одним автомобилем одним клиентом.

| Атрибут           | Назначение                                                |
| ----------------- | --------------------------------------------------------- |
| `ownership_key`   | Surrogate primary key записи факта                        |
| `ownership_id`    | ID владения из OLTP-системы PitGo                         |
| `customer_key`    | FK на `dim_customer`                                      |
| `vehicle_key`     | FK на `dim_vehicle`                                       |
| `start_date_key`  | FK на `dim_date`, дата начала владения                    |
| `end_date_key`    | FK на `dim_date`, дата окончания владения                 |
| `ownership_type`  | Тип владения: `private`, `leasing`, `company` и т.д.      |
| `ownership_count` | Метрика количества владений, всегда равна `1`             |
| `duration_days`   | Продолжительность владения в днях                         |
| `is_current`      | Признак текущего владения: `1` — активно, `0` — завершено |

Главные **метрики** :

- `ownership_count` — количество владений через `SUM(ownership_count)`;
- `duration_days` — позволяет считать среднюю, минимальную и максимальную продолжительность владения;
- `is_current` — позволяет быстро считать количество текущих владений, например `SUM(is_current)`.
